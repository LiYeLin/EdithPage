## ISSUE-001：新增网站未获取网页图标

状态：已完成（2026-10-26）

用户反馈：添加新的网站标签后，没有拉取并显示对应网页图标。

预期与验收：

- 新增有效网站地址后，自动获取并显示该网站的图标。
- 保存、刷新页面后，图标仍能正常显示。
- 网站没有可用图标或获取失败时，显示可用的兜底图标，不出现破图。

处理结果：网页和插件统一使用“内置图标 → 所选远程服务 → 文字占位”。首次简体中文环境默认国内 Cravatar，其余默认 Google，设置中可手动切换；每个图片来源 8 秒超时后降级，不自动切换其他服务。请求只传域名，并禁止 Referer。服务返回的默认图标也作为有效占位，不能保证每个网站都能获得真实品牌图标。

同时完成：简体中文 / 英文界面，语言默认跟随浏览器，可手动切换；插件名称和描述本地化；语言与服务独立保存，兼容旧导航配置和备份。

验证：单元及组件测试、网页与四目标插件构建校验；浏览器测试覆盖新增站点、服务切换、刷新保留、失败占位和移动端英文设置。Chromium 实际加载插件，成功获取 Bilibili 图标，确认请求不携带页面参数和 Referer。Edge、360、QQ 本轮仅验证构建，未做对应浏览器真机测试。当前执行环境无法直连 Google，其地址生成、切换和图片加载流程使用模拟响应验证，尚未完成海外网络实测。

## ISSUE-002：气泡模式新增分组导致页面向下滚动

状态：已完成（2026-10-26）

用户反馈：气泡模式下新增分组会向下追加，导致需要向下滚动才能看到内容，不符合导航页一屏可见的使用预期。

确认方案与验收：

- 面向桌面网页与插件，以浏览器实际可用宽高和各分组的网址数量试排，不按分辨率写死分组上限。
- 所有组内网址直接展示，取消横向分页。正常容量内全部分组和网站入口一屏可见，保留文字、点击区域与动画活动空间。
- 新增分组、添加网址、表单改分类和跨组拖拽先检查候选布局；放不下时拒绝保存并保留输入，失败移动不产生定位和撤销记录。
- 缩小窗口、导入、撤销等导致已有内容超限时，保留数据并临时启用纵向滚动。单组宽于窗口时改为网址换行面板，窗口恢复后自动回到一屏气泡布局。

处理结果：使用现有 D3 生成圆形排列候选，并与按行排列比较；检查实际气泡、标题、操作按钮和窗口边界，优先保留既有位置。先收紧间距，再切换紧凑图标尺寸；图标不小于 40px，网址操作区域不小于 44px，不通过整体缩放压小文字。解除气泡内容区域的 1500px 宽度限制，并让顶部留白随高度收紧。容量试排为确定性启发式，不保证数学最优装箱。布局和容量不写入配置或备份。

验证：450 项单元/组件测试和 71 项浏览器测试通过，覆盖 1366×768、1920×1080、2560×1440、3840×2160，一屏新增、超限保留输入与数据、超宽分组降级、窗口恢复、减少动态、长按编辑、鼠标/触摸/键盘移动与撤销。Lint、网页构建、Chrome/Edge/360/QQ 插件构建校验通过。实际加载 Chromium 插件验证新增、拒绝超限、扩大窗口恢复及扩展存储刷新保留，无页面运行错误。浏览器缩放的空间变化使用 CSS 视口缩小模拟；未做真实显示器或系统缩放测试。Edge、360、QQ 本轮仅验证构建。

## ISSUE-005：编辑模式删除红叉的实际点击区域过小

状态：已完成（2026-10-27）

用户反馈：长按网站图标进入编辑模式后，只有点击删除红叉的最中心才能删除，稍微偏离中心就不生效，实际点击区域与显示区域不符。

预期与验收：

- 删除红叉的有效点击区域覆盖整个可见按钮区域，位置与显示位置一致。
- 点击按钮中心及靠近四周边缘的位置，均能正常触发对应网站的删除操作。
- 鼠标点击和触屏点按均验证，避免拖拽、长按或其他元素遮挡导致点击失效。
- 点击红叉不误触网站跳转、拖拽或其他网站的删除操作。

复现与原因：红叉的 `pointerdown` 向上冒泡，触发气泡整体按压回弹。鼠标按下约 90ms 后，按钮移动约 15px，松开时已落在其他元素上，导致删除失败甚至退出编辑模式；中心点击也可能失败。

处理结果：编辑模式禁用整体按压回弹，并在普通模式排除链接、按钮等控件的按压事件。保留皮肤高光和拖拽接触形变；模式切换时清理已有按压动画。删除按钮从缩放后约 17px 调整为实际 24px，视觉与点击区域同步。

验证：新增浏览器回归覆盖 1920×1080、1366×768，气泡内与常用栏、鼠标和触屏模拟，共 40 个中心/四边点击点，全部正常删除，无跳转、误拖拽或误删其他站点。459 项单元/组件测试、Lint、网页构建和 Chrome/Edge/360/QQ 插件构建校验通过。实际加载 Chromium 插件验证中心与四边删除、扩展存储、撤销及刷新，无运行错误。触屏仅模拟，Edge、360、QQ 未做对应浏览器实际验证。

原有模板交互 22 项复跑通过，包含鼠标/触屏/键盘拖拽、取消、撤销与减少动态。首次运行的键盘取消用例在长按进入编辑阶段偶发失败，独立连续重跑 3 次及整文件复跑均通过；本轮未修改该用例。
