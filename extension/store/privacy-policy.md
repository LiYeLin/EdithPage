# Edith 新标签页隐私政策

更新日期：2026-10-26

Edith 开发者不会收集、接收或出售用户的导航配置、访问计数及搜索词。用户创建的导航配置、访问计数和引导状态仅保存在浏览器提供的本地扩展存储中。

扩展默认使用浏览器设置的搜索引擎。用户主动提交搜索时，查询词会交由浏览器默认引擎或用户在当前页面主动选择的搜索引擎处理，用于提供搜索结果，适用该搜索服务的隐私政策。Edith 不保存搜索词，也不将查询发送至开发者服务器。临时引擎选择不保存，每次打开或刷新扩展页均恢复浏览器默认。旧版或网页版备份中的搜索引擎偏好可保留用于迁移，但不会影响扩展默认搜索。

扩展不使用统计分析、广告、远程代码或后台服务，也不会读取浏览历史、书签、标签页内容或网页内容。用户主动点击导航链接和执行搜索时，会直接访问用户选择的网站或搜索引擎，该行为受对应网站的隐私政策约束。

网站图标优先使用随插件提供的本地图片。没有可用本地图标时，插件会向所选的图标服务请求图片：国内服务为 Cravatar（cn.cravatar.com），海外服务为 Google（www.google.com/s2/favicons）。首次简体中文浏览器环境默认使用国内服务，其余默认使用 Google；这不涉及定位或 IP 地理查询，用户可在设置中手动切换。请求只包含网站域名，不包含导航网址中的路径、查询参数、账号密码或搜索词，并设置不发送 Referer。服务商在提供图片时仍会接收到网络请求的 IP 等常规连接信息，适用其自身隐私政策。获取失败或超时显示本地文字占位，不会自动切换另一家服务。

界面语言和图标服务选择仅保存在本机。切换语言不会修改用户的站点名、分类名或已经选择的图标服务；导航 JSON 备份暂不包含这两项本机偏好。

用户可以在设置中导出 JSON 备份、导入备份或恢复默认配置。卸载扩展后，浏览器将按照自身规则删除扩展本地数据。
