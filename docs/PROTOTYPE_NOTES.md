# 程序员导航模板原型说明

## 要验证的问题

一个程序员导航站是否可以同时保持高质感视觉、快速搜索和轻量自定义，而不变成传统书签宫格。

## 当前方案

- 深色“开发工作台”视觉，使用薄荷绿与星云紫作为动态光源。
- 搜索是第一交互入口，支持 Google、Perplexity AI、百度切换。
- 内容模块采用开放式面板与站点行，减少多层卡片嵌套。
- 站点图标默认按域名加载 favicon，失败时回退到名称首字母。
- 自定义配置包含工作台名称、主题色、添加站点、新建模块和编辑移除。
- 配置保存在浏览器 localStorage，原型阶段不依赖账号或后端。

## 后续待确认

- 是否增加更多职业模板及模板选择 onboarding。
- 是否需要拖拽排序、云端同步、导入导出和多人共享。
- 最终品牌名称与正式视觉资产。
