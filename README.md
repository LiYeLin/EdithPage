# Edith（伊迪斯）程序员导航原型

一个可配置的程序员导航站模板，包含：

- Google、Perplexity AI、百度搜索切换
- AI 工具、AI 学习、开发工具、技术社区模块
- 默认读取网站 favicon
- 添加站点、添加模块、移除站点、切换主题色
- 配置自动保存在浏览器 `localStorage`
- 桌面端与移动端响应式布局

## 本地运行

```bash
npm install
npm run dev
```

## 构建与检查

```bash
npm test
npm run lint
npm run build
npm run preview
```

> 原型代码用于验证视觉方向和配置体验，后续确定方案后可再补充路由、账号同步与云端配置。

## 气泡布局实验

实验分支：`codex/bubble-modules`。`main` 保留实验前的面板布局。

- 分类使用毛玻璃圆形气泡，新增站点时膨胀、删除时收缩；“最常使用”仍保留原来的快捷栏。
- 复用 `d3-hierarchy` 的 `packSiblings` / `packEnclose` 计算图标排布及边界，复用 Motion 的布局弹簧动画；未引入自写物理引擎。
- 气泡大小根据站点数递增，达到视口安全上限后改为内部滑动分页，不持续放大、缩小图标或限制可保存的站点数。添加入口占固定位置，进入编辑模式不会单独触发膨胀。
- 平板/手机可在分类标题或气泡间隙处横向滑动切换分类；有多页的气泡内横向滑动或点箭头切换站点页。
- 保留搜索自动聚焦、长按编辑、删除撤销、空白处退出编辑、原配置和使用次数存储键。

布局测试使用 Node.js 22.18+ 自带的 TypeScript 类型剥离及测试运行器，无新增测试框架：

```bash
node --experimental-strip-types --test tests/bubble-layout.test.ts
```

切换两个版本时运行 `npm install` 以同步对应分支的依赖。Git 分支不会隔离浏览器的 `localStorage`；试验中对站点的修改会被两个布局共用。

## 跨分类拖放与水滴特效

- 使用 `@dnd-kit/core` 处理拖放，精确锁定 `liquid-gooey@0.2.1` 绘制水滴与边缘短桥，Motion/D3 保持原有布局分工。图标和名称独立于 SVG 滤镜，保持清晰。
- 长按任一图标进入编辑模式后，电脑可直接拖到其他分类的气泡内；手机按住约 220ms 再拖动，快速划动仍用于翻页。
- 平板/手机将图标停在分类区域左右边缘可自动滚动。仅分类气泡接收站点，“最常使用”可作为拖动来源但不是独立分类。
- 松手后一次更新源分类与目标分类；同分类或无效区域放下不修改数据，`Escape` 取消当前拖动。成功移动后 5 秒内可撤销，恢复原分类及顺序。
- 有分页时会展示新站点所在页；网站 ID、使用次数和原有本地存储格式保持不变。
- 编辑模式下也可聚焦图标，按空格提起、方向键选择分类、空格或回车放下，`Escape` / `Tab` 取消；普通回车仍编辑站点。
- `npm test` 运行气泡排布、分类移动及圆形命中单元测试（Node.js 22.18+）。浏览器交互验证使用独立测试上下文，不修改用户当前浏览器的数据。

- 水滴层独立于 draggable 节点存活：提起、源边缘分离、真实目标高亮、松手归位与取消返回；最常使用来源仅有局部涟漪，不向远处分类拉丝。
- 数据与撤销从有效松手立即生效，视觉归位不超过 360ms；目标只暂时隐藏视觉并保留布局，收尾后恢复焦点。新操作可以立即中断旧动画。
- 键盘、`prefers-reduced-motion: reduce` 和 SVG 能力不可用时，回退普通预览与静态落点光圈；减少动态支持运行中切换。
- 当前 36 项单元测试；浏览器验证包含桌面、785×568 与 390×844 触摸模拟。真实移动 Safari 与实机流畅度仍待验证。
- 详细状态、参数及验证边界见 `docs/EFFECTS_AND_ANIMATION_SPEC.md` 第 0 节；后面的历史方案保留原貌。
