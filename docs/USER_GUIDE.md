# 功能与使用

## 搜索与导航

搜索区可切换 Google、Perplexity AI 和百度。提交后在新标签页打开搜索结果；空搜索打开引擎首页。页面初次加载自动聚焦搜索框，`⌘K` / `Ctrl+K` 可重新聚焦。切换模板保留尚未提交的搜索词。

“最常使用”最多展示 7 个站点，按本应用记录的访问次数排序，同次数使用默认偏好和原有顺序。它不是浏览器历史记录，也不是独立分类。

## 模板

从顶部“切换模板”入口选择外观。模板共享分类、站点和访问次数，切换不会载入另一套站点预设。拖拽或归位期间不能切换；加载失败可重试。

| 模板 | 布局与操作 |
| --- | --- |
| 液态气泡 | 按实际窗口空间和网址数量动态排布，全部网址直接展示；编辑模式支持跨分类拖放 |
| 物理图标 | 站点以矩形/多边形掉落、碰撞、堆叠，可拖动位置 |
| 北京地标 | 图标落在天坛、故宫和中国尊线稿地形上，可拖动探索；地形加载失败可重试 |
| 纯净应用网格 | 按分类展示图标网格；编辑模式通过“移动到”选择目标分类 |

气泡模板不按分辨率设置固定分组上限。新增分组、添加网址或跨组移动前，会按当前窗口实际可用宽高试排；空间不足时不保存该操作，并保留输入。布局会先收紧间距，再使用紧凑图标尺寸，不无限缩小文字和点击区域。

气泡内的网址按行居中排列。添加按钮的位置始终预留，进入或退出编辑模式时已有网址不会因按钮显示或隐藏而移动。

缩小窗口、导入、撤销或切换模板后，已有内容可能超出容量。此时保留全部内容，临时允许纵向滚动并提示整理；单组宽于窗口时改为网址换行的圆角面板。窗口空间恢复后自动回到一屏气泡布局，不使用横向翻页。这项容量适配面向桌面浏览器与扩展，不以手机为验收目标。

物理模板内拖动图标改变空间位置，不等于改变分类；需要调整分类可使用站点编辑表单。

## 编辑与撤销

设置抽屉支持新增分类、添加站点、编辑名称/网址/所属分类，以及分类强调色。全局统一使用默认配色，不再提供主题色和“一句话描述”配置。网址未包含 HTTP(S) 前缀时自动补 `https://`。

气泡等站点入口支持长按编辑；纯净网格有明确的编辑按钮。进入编辑后可编辑或删除站点，模板提供对应的分类操作。点击空白区域或在没有弹层和拖拽时按 `Escape` 退出编辑。

删除站点、删除分类以及通过公共移动动作跨分类移动后，可在 5 秒内撤销最近一次操作；新操作替换旧撤销记录。站点编辑表单内直接变更分类不会生成移动撤销提示。

气泡拖放支持鼠标、触摸和键盘：编辑模式中聚焦图标，空格提起、方向键选择分类、空格/回车放下，`Escape` / `Tab` 取消。同分类或无效目标不修改配置。“最常使用”可作为拖动来源，不作为投放分类。

## 位置保存与备份

物理图标、北京地标的设置中有“保存图标位置”，默认关闭，两套模板分别保存。开启后刷新会恢复保存位置并继续物理模拟，关闭后重新掉落。该选项不保存速度，也不冻结图标。

在设置中导出 JSON 备份，可在另一网页环境或扩展中导入。导入会提示覆盖配置，成功后重新加载页面。备份包含分类、站点、模板、主题色、位置配置、搜索引擎、访问次数和引导状态；文件中缺少的受管理存储键会被清除。

“恢复默认”恢复默认内容和主题色，保留当前模板；不会清空独立保存的搜索引擎、使用次数和引导状态。

## 动态效果边界

气泡液态拖拽在减少动态、键盘操作或 SVG 能力不可用时使用普通预览与静态落点。北京地标在减少动态模式下使用可操作的静态列表。物理图标当前没有相同的静态列表降级，不能视为已完整支持减少动态。

响应式和触屏回归使用浏览器仿真，不能代替真实手机 Safari 或设备性能验证。持久化失败时配置修改仍可在当前页面使用，但刷新后可能丢失。

## 语言和网站图标

设置中可选择“跟随浏览器 / 简体中文 / English”。语言切换覆盖界面、引导、提示和无障碍说明，已保存的站点名、分类名保持原文。插件名称与描述随浏览器的扩展语言显示。

首次创建默认导航内容时，分类、站点名和说明使用当前界面语言；“恢复默认”也使用当前语言。切换语言不会改写已有导航内容，包括之前保存的默认分类。引导支持点击和触屏操作，最后一步点击“完成 / Done”结束。

图标服务独立选择“国内服务（Cravatar）”或“Google 服务”。首次简体中文环境默认国内服务，其余默认 Google；语言只用于初始默认判断，不会查询用户所在地。手动切换服务后立即生效，刷新后保留，切换界面语言不会改变服务。

图标加载顺序为内置图片、所选远程服务、文字占位。每个来源最多等待 8 秒，失败后降级；服务自身返回的默认图标也作为占位显示，不保证所有网站都有真实品牌图标。只发送网站域名，不发送具体页面路径或查询参数。网页和插件行为一致。
